# BookMyShow Clone (MERN) v2

Features: login, movies, city filter, seat booking, Razorpay payment (demo mode without keys),
email confirmations (optional), cancel booking, admin page.

## Run
1. Start MongoDB (local) or put an Atlas URL in server/.env
2. Terminal 1:  cd server && npm install && npm run seed && npm run dev
3. Terminal 2:  cd client && npm install && npm run dev
4. Open http://localhost:5173
